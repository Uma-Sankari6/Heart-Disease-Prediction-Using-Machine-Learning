# Heart Disease Prediction Using Machine Learning

## About the Project

This project uses Python and Machine Learning to predict the presence of heart disease using a heart disease dataset.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest

## Project Workflow

1. Load the dataset
2. Explore and analyze the data
3. Preprocess the data
4. Encode categorical values
5. Split the data into training and testing sets
6. Train the Machine Learning model
7. Make predictions
8. Evaluate the model

## Machine Learning Model

Random Forest Classifier

## Project Type

Data Science / Machine Learning

## Disclaimer

This project is created for educational purposes and should not be used as a medical diagnosis tool.
